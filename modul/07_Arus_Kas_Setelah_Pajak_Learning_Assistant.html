Arus Kas Setelah Pajak

Baca halaman pembuka ini sebelum memulai praktikum. Setelah siap, pilih Mulai Praktikum untuk masuk ke simulator dan mengikuti Learning Assistant.
Estimasi waktu60–75 menit

Prerequisite Topik

  • Memahami arus kas sebelum pajak dan konsep Nilai Waktu Uang.
  • Memahami depresiasi dan nilai buku aset.
  • Memahami konsep tarif pajak dan tax shield.

Capaian Pembelajaran

  1. Menyusun dan membandingkan before-tax cash flow dan after-tax cash flow.
  2. Menjelaskan pengaruh depresiasi terhadap tax shield.
  3. Menghitung dan menginterpretasikan after-tax NPW/IRR.

Aturan Pengerjaan

  1. Kerjakan modul ini secara berurutan dan fokus pada satu topik sebelum berpindah ke modul berikutnya.
  2. Ikuti Learning Assistant dengan urutan istilah yang sama: Tujuan Belajar → Prediction Before Run → Atur Parameter → Jalankan Simulasi → Amati Hasil → Contextual Explanation → Checkpoint Quiz → Learning Summary.
  3. Sebelum simulasi pertama, jawab Prediction Before Run. Jangan langsung menekan PLAY/RUN/AUTO ANALYZE tanpa membuat prediksi.
  4. Ubah parameter secara terkontrol. Untuk mengamati sebab–akibat, prioritaskan perubahan satu parameter pada satu eksperimen.
  5. Amati grafik, timeline, result card, perhitungan, dan indikator keputusan. Catat data eksperimen bila fitur Record Data tersedia.
  6. Selesaikan Checkpoint Quiz dan baca Learning Summary sebelum mengakhiri modul.
